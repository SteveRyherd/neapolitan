# design-assets-v1

First public release of the Neapolitan design source files.

This bundle contains the Photoshop sources behind every illustrated element in the extension — the hero illustration, badge mark, options-page logo, environment icons, and keyboard shortcut illustrations. Download `design-assets-v1.zip` to get them all in one archive.

## Contents

| File | Purpose |
|------|---------|
| `hero.psd` (40 MB) | Marketing hero illustration |
| `options_page_logo.psd` (15 MB) | Logo for the options page |
| `keyboard_shortcut_icons.psd` (9 MB) | Keyboard shortcut illustrations |
| `badge.psd` (7 MB) | Neapolitan badge / extension icon |
| `icon_production.psd`, `icon_production2.psd` | Production-environment icon variants |
| `icon_staging.psd`, `icon_staging2.psd` | Staging-environment icon variants |

Total uncompressed: ~71 MB. Zip is ~30 MB.

## How to use

Open the PSDs in Photoshop, [Photopea](https://www.photopea.com/) (free, browser-based), or GIMP (limited PSD support). See `design/SOURCES.md` in the repository for documentation on how each source file maps to the assets shipped in the extension and on neapolitan.page.
